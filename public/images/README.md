# Gambar untuk kartu besar di homepage

Taruh file gambar di folder ini dengan nama berikut agar otomatis muncul di kartu — tidak perlu mengubah kode apa pun:

- `checklist-preview.png` (atau `.jpg`) — gambar untuk kartu "Compliance Checker"
- `pustaka-preview.png` (atau `.jpg`) — gambar untuk kartu "Pustaka Regulasi"

Rasio yang disarankan: 16:10 (misalnya 1600x1000px atau lebih besar). Sebelum file ditambahkan, kartu otomatis menampilkan kotak placeholder berwarna sesuai palet situs, jadi tampilan tetap rapi. Setelah file dengan nama persis seperti di atas ditambahkan ke folder ini, commit dan push seperti biasa — gambarnya langsung muncul menggantikan placeholder.
